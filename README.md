AI RAG Chatbot with Multi-Tool Agent using LangGraph & Ollama

Developed an AI-powered conversational chatbot using Python, LangGraph, LangChain, and Ollama, capable of answering user queries through Retrieval-Augmented Generation (RAG), 
web search, and custom tools.

Built a RAG pipeline by extracting text from PDF documents, generating embeddings with Nomic Embed, indexing content in FAISS, and retrieving relevant context for accurate
document-based question answering.

Integrated multiple AI tools including DuckDuckGo Search, live stock price retrieval, calculator, and date/time utilities using LangChain tool calling to extend chatbot 
capabilities.

Implemented a stateful multi-agent workflow using LangGraph with conditional tool execution, persistent conversation history using SQLite, and thread-based document management 
for scalable user interactions.

Designed a modular architecture supporting secure environment variable management, efficient document chunking, vector search, and reusable components for production-ready deployment.
